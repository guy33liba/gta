# Urban Heat

Original browser-based open-world 3D action game prototype.

## Stack

- Babylon.js 9.x
- TypeScript
- Vite
- WebGPU first, WebGL2 fallback
- GLB/glTF asset pipeline planned
- Desktop and mobile browser target

## Current vertical slice

- Procedural city block
- Third-person camera
- Playable character
- Drivable prototype vehicle
- Enter/exit vehicle interaction
- Responsive HUD
- Browser-native loading screen

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

The project is intentionally original and does not use GTA/San Andreas copyrighted assets, characters, maps, names, or branding.
